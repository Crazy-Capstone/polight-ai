청구서류 조사 자료 (2026-11-21)

catalog.json: 7개 보험사, 8개 안내 프로필. 운영 DB 저장명에 맞춰 한화손해보험과 캐롯손해보험을 독립 보험사로 분리하고, 삼성 재물/의료 안내도 별도 보관한다.
research_source.txt: 사용자 첨부 원문 바이트 그대로 보존. 원문 수정이나 누락 여부를 확인하는 자료다.
review.json: 실제 공식 링크 확인 결과와 수정·분류·재확인 사항.
db_non_travel_reference.json: 여행보험에 자동 적용하지 않는 DB 일반 질병·상해·운전자 관련 조사자료.

자료 사용 방식
- insurers[].profiles[] 안에서 현재 증권의 상품/채널과 맞는 프로필을 고른다.
- 공통 그룹과 해당 사고 유형 그룹만 선택한다. 다른 프로필의 공통서류를 합치지 않는다.
- groups[].requirements[].text는 원문 조건·예시를 유지한 서류 묶음이다. 한 항목이 서류 한 개라는 뜻은 아니다.
- conditionText가 없더라도 text 내부에 제출 생략·대체·금액·미성년자·수리 가능 여부 조건이 있을 수 있다.
- issuerText는 조사자료 표의 발급처 원문이다. 정확성이 확인되지 않은 표기는 review.json에 남겼다.
- 공통의 NOTICE 항목은 제출 서류가 아닌 안내 문구다.
- guideUrl은 목록 전체에 적용할 보험사 공식 안내 주소다. 서류별 URL 또는 양식 파일은 응답에 넣지 않는다.
- automaticSelectionAllowed=false는 공식 본문 확인이 불충분하거나 해결하지 않은 이슈가 있는 보수적 검토 표시다.
- 검토 표시는 현재 챗봇에 연결되어 있지 않다. 응답 스키마·보험사 조회·사고 분류 구현은 이번 작업에 포함하지 않는다.
- 보상금액/가입 여부/보장 조건은 증권·약관에서 판단한다. 이 카탈로그로 판단하지 않는다.

재생성
python scripts/prepare_claim_document_catalog.py <원본 조사 텍스트 경로>
원문은 변경하지 않는다. catalog.json은 정규화된 데이터이며 줄바꿈/Markdown 강조는 정리되어 있다.
검토 상태는 2026-11-21 확인 결과다. 링크 접근 실패를 페이지가 없거나 자료가 틀렸다는 뜻으로 해석하지 않는다.
