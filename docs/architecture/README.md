## 담고 있는 것

1. **기술 스택** — AI 서버 · 백엔드 서버 · 데이터/인프라 · 외부 AI API를 로고와 함께 분류
2. **배치 구성** — EC2 1대 안의 컨테이너 3개, compose 분리 이유, 메모리 한도
3. **플로우 01 증권 분석** — 업로드 → S3 → 202 접수 → Upstage Studio Agent → 콜백 → 담보 저장 (16단계 시퀀스)
4. **플로우 02 약관 색인** — 파싱 → 청킹 → 임베딩 → `policy_terms_chunks` / 보장 규칙 추출 배치
5. **플로우 03 증권 ↔ 약관 연결** — 약관 선택 4단계, 담보 규칙 연결 4단계
6. **플로우 04 챗봇 RAG** — 하이브리드 검색(벡터 + BM25) → RRF → MMR → 답변·인용
7. **계약·안전망** — 재시도/타임아웃 값과 그 값이 없을 때 생기는 일, 보안 경계
8. **데이터 모델 · 배포 파이프라인**

## 고칠 때

`system-architecture.html` 하나가 전부다(외부 리소스는 Google Fonts뿐).
다이어그램은 손으로 쓴 인라인 SVG이고, 색은 CSS 변수(`--be` 백엔드 / `--ai` AI / `--db` 데이터 / `--ext` 외부)를 그대로 참조하므로
라이트·다크 테마가 함께 따라온다. 좌표를 바꿀 때는 라벨이 박스와 겹치지 않는지 브라우저에서 확인한다.
