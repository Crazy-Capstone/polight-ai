# S16. 학습·추론 원가 (Unit Economics)

> 멘토링 3회차 지시사항 — "파싱 비용·토큰 비용·서버 운영비를 포함한 학습·추론 원가를 추정하라"에 대한 답

실제 API 단가와 실측 처리량으로 계산한 **사용자 1인당 원가**입니다.
(가정: 증권 1건 + 약관 1건 + 질의 5회 / 환율 1 USD = 1,400원)

---

## 1인당 원가 (장표용)

| 항목 | 처리 방식 | 원가 |
|---|---|---|
| **증권 파싱·Extract** | 3페이지, 1회 처리 후 결과 DB 캐싱 | **₩170** |
| **약관 파싱·청킹·임베딩** | 보험사당 1회 (사용자 수 무관) | **₩3,440 / 보험사 → 사용자당 분할 시 ≈ 0** |
| **질의 추론 토큰** | 5회 × RAG(선별 조각만 전송) | **₩160** |
| **인프라** | EC2(t3.medium) + S3 + pgvector | **₩55,000 / 월** |
| **1인당 변동비 합계** | 증권 + 질의 | **약 ₩330** |

**핵심 논리 2가지**
1. 약관은 사용자당이 아니라 **보험사당 1회만 인덱싱** → 사용자가 늘어도 임베딩 비용은 늘지 않음
2. **Extract 선캐싱**으로 반복 추론 제거 → 대시보드는 매번 LLM을 호출하지 않음

**결론: 1인당 원가 ₩330 대비, 이용료 ₩1,900 → 손익분기 약 35명/월**

---

## 계산 방법 (근거)

### 적용 단가 (2026년 8월 기준, 실제 요금)

| 서비스 | 단가 |
|---|---|
| OpenAI GPT-4.1 | 입력 $2 / 출력 $8 (per 1M 토큰) |
| Upstage Parse + Extract | $0.04 / 페이지 |
| Upstage 임베딩 | $0.02 / 1M 토큰 |
| AWS EC2 t3.medium (서울) | 약 $38 / 월 |
| 환율 | 1 USD = 1,400원 |

### ① 증권 파싱·Extract — ₩170

```
증권 평균 3페이지 (실측: 메리츠 4p·신한 3p·기타 2p 평균 3.0p)
Parse+Extract $0.04/페이지 × 3페이지 = $0.12
$0.12 × 1,400원 = 168원 ≈ ₩170

→ 1회 처리 후 결과를 DB에 캐싱하므로, 이후 대시보드 조회는 추가 비용 0
```

### ② 약관 파싱·청킹·임베딩 — ₩3,440 / 보험사 (분할 시 ≈ 0)

```
파싱   : 246페이지 × $0.01 = $2.46
임베딩 : 323청크(약 18만 토큰) × $0.02/1M = $0.004
합계   : $2.46 × 1,400원 = 3,444원 ≈ ₩3,440

→ 보험사당 딱 1회만 색인. 사용자 N명이 공유하므로
   1인당 = 3,440원 ÷ N → 사용자가 늘수록 0에 수렴
```

### ③ 질의 추론 토큰 — ₩160

실측 토큰 기준 (질의 1회 = 답변 생성 + 질문 재작성):

```
답변 생성 1회
  입력 : 9,871 토큰 (시스템 프롬프트 2,068 + 근거 8조각·증권 담보 7,803)
  출력 : 약 180 토큰
  비용 : 9,871 × $2/1M + 180 × $8/1M = $0.0212

질문 재작성 1회
  입력 600 · 출력 60 토큰 = $0.0017

질의 1회 합계 = 약 $0.023
질의 5회      = $0.114 × 1,400원 = 160원 ≈ ₩160

→ RAG로 약관 200페이지 전체가 아닌 '선별된 8조각'만 LLM에 전송해
   토큰을 최소화 (long-context 대비 비용 대폭 절감)
```

### ④ 인프라 — ₩55,000 / 월

```
EC2 t3.medium (AI 서버 + pgvector 도커 동거) : 약 $38/월
S3 + 데이터 전송                              : 약 $2/월
합계 : $40 × 1,400원 = 56,000원 ≈ ₩55,000/월 (고정비)
```

---

## 손익분기 계산 — 약 35명 / 월

수익모델(Week3 확정): **여행 1회당 기본 이용료 ₩1,900** (고부가 기능 ₩5,900)

```
1인당 변동비 : 증권 170 + 질의 160 = ₩330
1인당 매출   : ₩1,900 (기본 이용료)
1인당 마진   : 1,900 - 330 = ₩1,570

인프라 고정비 : ₩55,000 / 월

손익분기 = 55,000 ÷ 1,570 ≈ 35명 / 월
```

**월 35명만 유료 결제하면 인프라 고정비를 회수합니다.**
고부가 기능(₩5,900) 이용자는 1인당 마진 ₩5,570 → 손익분기 약 10명.

---

## 원가 구조의 경쟁력 (장표 메시지)

```
변동비(사용자당)     증권 170 + 질의 160 = ₩330   ← 사용자당 발생, 그러나 작음
고정비(공유·1회성)   약관 색인(보험사당 1회) + 인프라(월 5.5만원)
```

- 사용자가 늘어도 **약관·인프라는 고정**, 늘어나는 건 1인당 ₩330뿐
- 이용료 ₩1,900 대비 원가 ₩330 → **마진율 약 83%**
- 손익분기 **35명/월**로 낮아, 초기 소규모 트래픽에서도 인프라 회수 가능

---

## 가정·주의 (각주용)

- 환율 1 USD = 1,400원 (2026년 8월 기준, 보수적)
- 증권 3페이지: 실측 3건 평균. 증권이 길어지면 ① 비용이 비례 증가
- 질의 토큰(9,871)은 근거 8조각을 모두 채운 **상한값** → 실제 평균은 이보다 낮을 수 있어 ₩160은 보수적(넉넉한) 값
- 인프라는 t3.medium 단일 인스턴스 기준. 트래픽 증가 시 스케일업 필요
- 손익분기는 **인프라 고정비 회수 기준**(약관 초기 색인비는 보험사당 1회로 별도)
